# 離線操作（山上模式）

佛堂有時在山上上課，網路訊號很差。雲端版網頁可以離線打開、離線點名加分，網路好時再上傳到後台。單機版本來就不需要網路，不受影響。

## 使用方式

| 狀況 | 畫面上方 | 說明 |
|---|---|---|
| 連不上後台（自動判斷） | 📴 離線中，有 N 筆尚未上傳 | 送不出去、或等超過約 8 秒沒有回應，就自動改成離線暫存 |
| 山上模式（手動開關） | ⛰️ 山上模式（不連線），有 N 筆尚未上傳 | 右上角 ⛰️ 按鈕。開啟後完全不嘗試連線，直接暫存；這支手機會記住這個設定 |
| 有網路、還有未上傳的資料 | 📶 有 N 筆尚未上傳［立即上傳］ | 通常會自動上傳；也可以按「立即上傳」 |
| 登入過期 | 🔒 有 N 筆尚未上傳：請重新登入［重新登入］ | 未上傳的資料保留在手機，重新登入後自動上傳 |
| 上傳時被後台擋下 | ⚠️ 有 N 筆上傳被後台退回［查看明細］ | 列出每一筆的內容與原因，按「已確認，清除明細」才會消失 |

建議做法：上山前先在有網路的地方開一次網頁並登入（讓手機存下最新名冊與網頁檔案），上山後開啟 ⛰️ 山上模式；下山或網路恢復後關閉山上模式，網頁會自動上傳。

### 離線時可以做的事

- 點名報到、加減分（規則與自訂）、小隊／全體加減分、兌換禮品、服務人員點名
- 查看名冊、分數、已報到名單、榮譽榜、匯出 CSV

### 離線時不能做的事（按鈕變淡，按下會提示「需要網路」）

需要後台給新編號或要立即寫入後台的操作：新增或修改學員、班別、課次、禮品、服務人員，修改設定、撤銷紀錄、帳號管理、登入、下載備份與匯入資料。

## 運作方式

程式在 `src/ui/offline.js`（不碰畫面的規則，`tests/offline.test.js` 測試）與 `src/ui/app.js`（操作佇列）、`src/ui/sw.js`（Service Worker）。

### 網頁檔案（Service Worker）

- 建置時產生 `dist/web/sw.js`，與網頁一起發布到 GitHub Pages。
- 網頁先上網抓最新版；沒有網路或等超過 4 秒，改用手機上存的版本。Google 字型存過一次就直接用手機上的。
- `sw.js` 裡寫著網頁內容的版本指紋：網頁一改，`sw.js` 就不同，瀏覽器會自動安裝新版、清掉舊的快取。開著的網頁會提示「網頁已更新，重新整理後使用新版」。

### 名冊與資料（`attendpoint_cache`）

- 每次從後台讀到資料，就把最後一份後台確認的資料（含登入者）存在手機的 localStorage。開啟網頁時先用這份顯示，不必等後台；連上後只下載變動（見 [資料結構 → 雲端同步](data-model.md#雲端同步只傳變動)）。
- 登出時改存遮蔽名字的訪客版本，不把完整名冊留在手機。
- 容量：瀏覽器 localStorage 約 5M 字元。一個班一年約 0.9 MB 沒有問題；三個班一年約 4.3 MB 已接近上限（見 [壓力測試](stress-test.md)）。存不下時網頁會提示，並清掉舊的那份，把空間留給尚未上傳的操作（此時離線開啟會看不到名冊，但點名中途斷線不受影響）。

### 未上傳的操作（`attendpoint_outbox`）

- 只有加減分類操作（`points.checkin`、`points.award`、`points.batch`、`points.redeem`、`session.duty`）可以離線暫存：它們只用上課日期，課次由後台在同一個操作中建立，不需要事先拿到後台的編號。
- 每個操作按下去就存在手機，關網頁、重開手機都不會遺失；畫面上的分數是「後台資料＋尚未上傳的操作」重算出來的。
- 每筆操作帶一個 `clientId`。後台（`Code.js`）記住最近 400 個成功執行的編號（指令碼屬性 `APPLIED_OPS`）：網路不穩時網頁以為沒送到、再送一次，後台也不會重複加分。
- 上傳時每 30 筆合併成一次 `apiApplyBatch`，每筆各自檢查權限與規則（與平常合併送出相同）。
- 觸發上傳：網路恢復（瀏覽器的 `online` 事件）、每 30 秒的背景更新、按 ↻ 或「立即上傳」、關閉山上模式、重新登入。

### 被退回的項目（`attendpoint_conflicts`）

上傳時被後台擋下的離線操作（例如另一台已經幫同一位學員點過名、點數不足、權限不足）不會默默消失：記在手機，畫面上方顯示筆數，「查看明細」列出內容、原因、操作時間與退回時間，確認後才清除（最多保留 200 筆）。

後台整批出錯（例如系統忙碌、試算表逾時）時，離線暫存的操作留在手機稍後再試；剛按下、還沒存成離線的操作則照舊退回並提示。

### 限制

- 紀錄的時間（`at`）是上傳到後台的時間；上課日期（課次）以點名當時選的日期為準，出席與報表不受影響。
- 離線期間看不到其他手機的操作；同一位學員在兩支手機都點名時，後上傳的那筆會被退回並列在明細中。
- 未上傳的操作在上傳時以「當時登入的帳號」記錄操作人。
